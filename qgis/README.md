# QGIS package

Open `oil_spill_niger_delta.qgz`. Layers are relative paths into `../data/processed/*.geojson` (sites, footprints, NOSDRA/community points).

This is a **new** project built from the Python pipeline. Do not treat it as an edit of `bonga_spill_2026.qgz`. That file, if found, is a reference-layer source only.
Bulk RTC GeoTIFFs stay in `data/raw/` and are not packaged here.
